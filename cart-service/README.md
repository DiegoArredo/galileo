# 🛒 Cart Service

Carrito de compras, órdenes y pagos.

## 🚀 Instalación

```bash
cd cart-service
npm install
```

## ⚡ Ejecución

```bash
npm run start:dev  # Puerto 3004
npm run build
npm start:prod
```

## 📡 GraphQL Endpoint

```
http://localhost:3004/graphql
```

## 🧪 Tests

```bash
npm test
npm run test:e2e
```
