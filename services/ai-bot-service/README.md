# 🤖 AI Bot Service

Chatbot con NestJS + GraphQL inteligencia artificial.

## 🚀 Instalación

```bash
cd services/ai-bot-service
npm install
```

## ⚡ Ejecución

```bash
npm run start:dev  # Puerto 3001 - Modo desarrollo
npm run build      # Build de producción
npm start:prod     # Ejecutar build
```

## 📡 GraphQL Endpoint

```
http://localhost:3001/graphql
```

## 🧪 Tests

```bash
npm test           # Unit tests
npm run test:e2e   # E2E tests
```
