# 📚 Courses Service

Gestión de cursos, lecciones y catálogo.

## 🚀 Instalación

```bash
cd services/courses-service
npm install
```

## ⚡ Ejecución

```bash
npm run start:dev  # Puerto 3003
npm run build
npm start:prod
```

## 📡 GraphQL Endpoint

```
http://localhost:3003/graphql
```

## 🧪 Tests

```bash
npm test
npm run test:e2e
```
