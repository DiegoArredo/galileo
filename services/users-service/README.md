# 👥 Users Service

Gestión de usuarios, autenticación y JWT.

## 🚀 Instalación

```bash
cd services/users-service
npm install
```

## ⚡ Ejecución

```bash
npm run start:dev  # Puerto 3002
npm run build
npm start:prod
```

## 📡 GraphQL Endpoint

```
http://localhost:3002/graphql
```

## 🗄️ Database

PostgreSQL en `localhost:5432`

```bash
createdb users_db
```

## 🧪 Tests

```bash
npm test
npm run test:e2e
```
